## Non-Negotiable Rules

1. A claim never advances from a model statement alone.
2. A repo is analysis-only until its owner supplies a reviewed local or
   remote-bound external profile.
3. A task becomes patchable only after a sandboxed reproduction and
   immutable verification plan.
4. An overnight run opens only tested draft PRs after explicit saved
   consent; it never merges, deploys, or releases. First-run default is a
   read-only brief.
5. Safety and privacy may not be weakened to improve usefulness or autonomy.
6. Hardware, LAN, GitHub writes, scheduling, recovery, and overnight
   usefulness require real integration proof.
